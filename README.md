# automated-ml-pipeline

THIS IS A PYTHON DATA PIPELINE THAT CLEANS CUSTOMER SUPPORT EMAILS AND AUTOMATICALLY ROUTES THEM TO THE CORRECT DEPARTMENT USING MACHINE LEARNING TEXT CLASSIFICATION.

## KEY FEAUTURES
* Cleans dirty data and forces lowercase text uniformity using Pandas.
* Converts raw text strings into numerical features using TfidVectorizer.
* Automates routing decisions using a trained Logistic Regression Model
